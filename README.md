# Cerita Kita

SPA berbagi cerita menggunakan Story API Dicoding, Leaflet, Webpack, View Transition, Media Capture, dan aksesibilitas dasar.

## Menjalankan
1. `npm install`
2. `npm run start-dev`
3. Buka alamat yang diberikan webpack-dev-server.

## Build production
`npm run build`

Jangan sertakan `node_modules` pada ZIP submission.
